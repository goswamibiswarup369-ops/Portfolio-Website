---

## ✨ Features

- **Animated hero & about sections** — smooth entrance animations powered by Framer Motion
- **Scroll-triggered reveals** — sections and content animate into view using GSAP + ScrollTrigger
- **Interactive project gallery** — a horizontally scrollable showcase of selected projects with live GitHub links
- **Toolkit / capability grid** — organized breakdown of skills across Frontend, Backend, Mobile, and Data Analytics
- **Experience & internship timeline** — a running list of internships and the skills gained from each
- **Light/dark mode toggle**
- **Responsive design** — built mobile-first with clean, minimal aesthetics

---

## 🛠️ Tech Stack

- **Frontend**: React, Vite
- **Styling**: CSS (custom), responsive layouts
- **Animation**: Framer Motion, GSAP (with ScrollTrigger plugin)

## ⚡ How to Run Locally

```bash
git clone https://github.com/goswamibiswarup369-ops/Portfolio-Website.git
cd Portfolio-Website
npm install
npm run dev
```

Then open `http://localhost:5173` in your browser.
